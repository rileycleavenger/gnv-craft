# Hub Gainesville (3rd Ave)

1258 NW 3rd Ave. Completed 2020, 201 units / 661 beds, 7 stories (architect), ground-floor retail.

## How it is built now
- **Footprint:** the 2018 LiDAR predates it, so the outline comes from Overture Maps / OSM (7 floors) and is checked against the 2023 NAIP aerial photo.
- **Facade:** from Mapillary street photos (2021): red-brick base, white upper floors, dark-gray balcony stacks.
- **Interior:** generated corridors and units; rooftop pool only where the aerial photo shows one.
